账号密码管理器

简介

本地账号密码管理工具，支持明文密码与TOTP 动态验证码（Google Authenticator 等）。数据保存在浏览器 localStorage，支持 JSON 文件与二维码导入/导出（均可明文或加密），不会上传到任何服务器。

JSON 格式示例

{
  "version": 1,
  "accounts": [
    {
      "id": "abc123",
      "title": "示例网站",
      "username": "user@example.com",
      "password": "your-password",
      "totpSecret": "JBSWY3DPEHPK3PXP",
      "url": "https://example.com",
      "notes": "备注信息"
    }
  ]
}

password 与 totpSecret 可单独或同时填写；TOTP 密钥支持 Base32 格式（含空格，会自动忽略）。
